# SS Adventure

First-person sailing simulator of a Hallberg-Rassy 340 on the Straits of Mackinac.

TanStack Start + React + Three.js. Helm, coaming, and chase cameras. Wind, sheets, reefing, autopilot, VHF, and live instruments.

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:8080](http://127.0.0.1:8080), then **Cast Off**.

| Key | Action |
| --- | --- |
| A / D | Helm |
| W / S | Sheets |
| R | Reef |
| P | Autopilot |
| E | Engine |
| V | Cycle camera |
| M | Mute |

Private repo. Hallberg-Rassy 340 sailing physics, Mackinac world, and marine HUD.
